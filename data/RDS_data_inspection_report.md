# Q_Total_Data84 与 Macro_vars 数据检查报告

## 1. 总体判断

`Q_Total_Data84.rds` 不是原始 CRSP 行情表，而是一个已经加工好的公司—季度特征面板。公司特征被逐季横截面排序或分位数化到 `[-0.5, 0.5]`，因此数值代表相对位置，而不是原始财务比率或收益率的经济量纲。

`Macro_vars.rds` 是季度宏观/市场状态变量表。它和公司面板在 1984Q1–2020Q4 期间可以完整、多对一地合并，没有缺季。

## 2. CRSP 公司面板

- 对象类型：`tbl_df / data.frame`
- 规模：809,472 行 × 49 列；读入内存后约 296 MB
- 时间：1984-03-31 至 2020-12-31，共 148 个连续季度末
- 证券：21,227 个唯一 `permno`
- 主键：`date + permno` 无重复，适合作为面板键
- 每季度公司数：最少 4,060，中位数 5,465，最多 7,775
- 每家公司观测季度数：中位数 25；546 家覆盖全部 148 季度，252 家只有 1 季度

列由 45 个数值特征和 4 个标识/辅助字段组成：

| 字段 | 类型 | 含义 |
|---|---:|---|
| `date` | numeric | `YYYYMMDD` 格式的季度末日期，应转换为 `Date` |
| `permno` | numeric | CRSP 永久证券编号；值均为整数 |
| `Intervals` | factor | 分段时期；含一个未使用的 `1977-1983` level |
| `Early_Years` | logical | 证券记录开头的历史不足区间；最多覆盖开头 8 条记录 |

### 2.1 特征的尺度

所有 45 个公司特征都位于 `[-0.5, 0.5]` 内。它们的总体均值绝对值平均约 0.00082，中位标准差约 0.28847，几乎等于均匀分布 `U(-0.5, 0.5)` 的标准差 0.28868；抽查单个季度也得到同样结果。这强烈说明数据做过逐季度横截面 rank/quantile 变换。

其含义是：例如 `ME=0.4` 表示该公司当季市值相对靠前，而不是市值等于 0.4。这个处理削弱极端值影响，也丢失了原始经济量级。

按常见资产定价命名推断，变量大致包括：

- 估值与规模：`A2ME, B2M, CF2B, CF2P, D2P, E2P, ME, Q, S2P`
- 盈利和经营质量：`ATO, CTO, OP, PCM, PM, PROF, RNA, ROA, ROE`
- 投资、应计和资产负债：`AC, AT, C2A, D2A, DPI2A, INV, LEV, NI, NOA, OA, OL, SGA2S`
- 动量、交易与风险：`BETA_d, BETA_m, HIGH52, IdioVol, R2_1, R12_2, R12_7, R36_13, R60_13, RVAR, SPREAD, SUV, TURN, VAR`

RDS 内没有变量标签或其他元数据，缩写的严格公式仍应以生成代码或课程说明为准。

## 3. 宏观变量

- 对象类型：`data.table / data.frame`
- 规模：180 行 × 10 列
- 时间：1977Q1–2021Q4，连续且无缺失
- 主键：`Year + Quarter` 无重复
- 公司面板重叠期：1984Q1–2020Q4，148 个季度全部匹配
- 面板外宏观数据：1977–1983 和 2021，共 32 个季度

8 个宏观变量的命名与 Welch–Goyal 常用预测变量一致：

| 字段 | 很可能表示 |
|---|---|
| `dp` | 对数股息价格比 |
| `ep` | 对数盈利价格比 |
| `bm` | 账面市值比 |
| `ntis` | 净股票发行 |
| `tbl` | 短期国库券利率 |
| `tms` | 期限利差 |
| `dfy` | 违约收益率利差 |
| `svar` | 股票市场方差 |

这些变量没有缺失，但尺度差异很大。`dp/ep` 是负的对数比率，`bm` 为水平值，其余多为小数形式的利率、利差或方差。模型若对尺度敏感，应只使用训练期均值和标准差进行标准化。

宏观序列高度持久。在重叠期内，一阶自相关为：`dp 0.970`、`ep 0.909`、`bm 0.969`、`ntis 0.925`、`tbl 0.986`、`tms 0.905`、`dfy 0.807`、`svar 0.265`。`dp` 与 `bm` 的相关系数为 0.889，宏观变量之间也存在共线性。

极端季度与经济含义基本吻合：`svar` 和 `dfy` 的最高点均在 2009Q1；`tbl` 的最高值集中在 1984–1985；`tms` 在 2001Q1、2007 年和 2019Q4 出现负值。这是有利的数据合理性检查。

## 4. 合并与建模建议

1. 将 `date` 转为真正的日期，再提取 `Year` 和 `Quarter`；对宏观表做 `many-to-one` 合并，并保留合并完整性检查。
2. 当前公司表没有明显的未来收益目标变量。`R2_1`、`R12_2` 等按命名更像滞后收益特征；若任务是预测收益，还需另行定义或合并下一季度收益率。
3. 不要随机按公司—季度行拆分训练集和测试集。同一季度的宏观值会同时进入两边，造成严重时间泄漏。应采用按季度滚动或扩展窗口切分。
4. 会计特征和当季宏观值要核对信息可得日期。预测下一季度时，通常需要按实际发布日期滞后，不能只凭季度标签假设当期已知。
5. 对缺失值，可将横截面中位位置 `0` 作为一个自然插补基准，同时为每个变量增加缺失指示；应单独检验排除 `Early_Years` 行的稳健性。
6. 宏观变量在同一季度被复制给数千家公司，但宏观信息的有效时间样本只有 148。推断时至少按季度聚类标准误；面板模型常需公司和季度双向聚类。若每季度公司数差异不应改变权重，可给予每个季度相同总权重。
7. 若模型加入完整季度固定效应，宏观变量的主效应会被季度固定效应完全吸收。可估计宏观变量与公司特征的交互项，或改用不含完整季度固定效应的时间序列/两阶段设计。
